The learner — deconstruct, reconstruct, train

A definition is a sentence built from basic units. This page takes one apart to its units, rebuilds it from those units, and shows the weights it used. There is no server: the model is a single attention over the rules, a softmax, and a perceptron update — all of it in this page, saved in a cookie.
