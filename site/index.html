Symbology — the code, one cell at a time

Every unit of this code has a cell: the encoded character under its name on the left, its definition on the right. Units are grouped into sets; each set has a page. Combinations of the units in a set have pages of their own, where the definition is generated from the units' own definitions by a small set of rules. Everything is HTML, SVG and JavaScript — there is no backend, and the pages remember you with cookies.

The learner

  • Reconstruct a sentential definition

    Deconstruct a definition to its basic units, rebuild it, and train the attention weights. Weights and scores live in a cookie.

How the cells are related

  • Links. A unit links to the units whose definitions share words with it, to its own row, and to the combination page built from it.
  • Cookies. The pages remember which units you have visited, which row you were on, the tour position, and the learner's weights.
  • Page automation. Walk this page moves down the cells on a timer; j and k move by hand; the tour follows the links from set to set.
  • Wrapping HTML. The cell is the unit: a title cell, an encoded character cell, and a definition cell, in that order, in one row.
